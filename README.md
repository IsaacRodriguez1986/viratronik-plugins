# VIRATRONIK · Plugins gratuitos

## SPECTRONIC 0.14.1

Antes llamado **Spectrum**. Analizador para mezcla y producción musical: muestra forma de onda, espectro y espectrograma en tiempo real. Úsalo en una pista o en el canal máster para ver cómo se reparte la energía sin modificar el audio.

[![Interfaz de SPECTRONIC con el espectro y la forma de onda](https://viratronik.com/images/spectronic/spectronic-studio.png)](https://viratronik.com/herramientas/spectronic)

| Sistema | Formatos en el instalador |
| --- | --- |
| Windows x64 | VST3 |
| macOS 11 o posterior, Intel y Apple Silicon | VST3 y Audio Unit (AU) |

### Descargar e instalar

1. Abre la [ficha oficial de SPECTRONIC](https://viratronik.com/herramientas/spectronic) y descarga el instalador de tu sistema desde una cuenta gratuita de VIRATRONIK. Vincular el plugin después de instalarlo es opcional.
2. Cierra tu DAW. En Windows ejecuta el `.exe`. En Mac extrae el `.zip`, revisa la guía incluida y abre el `.pkg`.
3. Abre tu DAW, vuelve a explorar plugins si no aparece y busca **VIRATRONIK SPECTRONIC**. Para verificarlo, insértalo como efecto y reproduce audio. Si actualizas desde Spectrum, el nombre interno del paquete sigue siendo Spectrum para conservar tus sesiones existentes.

El instalador de Windows no tiene firma comercial y el de macOS no está notarizado por Apple. Descarga únicamente de la ficha oficial; no desactives la protección del sistema.
